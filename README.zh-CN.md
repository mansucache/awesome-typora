## 插件

- [Typora plugin](https://github.com/obgnail/typora_plugin) — 为 Typora 增加编辑与操作功能的插件集合。
- [Typora Community Plugin](https://github.com/typora-community-plugin/typora-community-plugin) — 社区插件系统，提供插件管理、命令面板等功能。
- [Collapsible Section](https://github.com/typora-community-plugin/typora-plugin-collapsible-section) — 折叠、展开 Markdown 章节，需配合 Typora Community Plugin 使用。
- [Typora Copilot](https://github.com/Snowflyt/typora-copilot) — 在 Typora 中使用 GitHub Copilot 和 Copilot Chat。
- [VLOOK](https://github.com/MadMaxChow/VLOOK) — 主题包与排版增强插件，适合用 Markdown 制作可分享的 HTML 文档。

这些是第三方项目，安装前请查看各自支持的 Typora 版本和系统。Copilot 等联网功能还需留意账号要求，以及哪些文档内容会发送给服务。

## 模板

- [typora-markdown-resume](https://github.com/CodingDocs/typora-markdown-resume) — 程序员简历模板，替换示例内容即可开始写。
- [LapisCV](https://github.com/BingyanStudio/LapisCV/blob/main/README-CN.md) — 用 Markdown 制作简历，支持 Typora、VS Code 和 Obsidian。

简历写完后，检查一下导出的字体和分页。

## 图片工具

- [PicGo](https://github.com/Molunerfinn/PicGo) — 带图形界面的图片上传工具，支持多种图床和插件。想在 Typora 中粘贴图片后自动上传，可以先看它。
- [PicList](https://github.com/Kuingsmile/PicList) — 在 PicGo 的基础上增加云端文件管理，适合需要浏览、删除远端图片的人。
- [PicGo-Core](https://github.com/PicGo/PicGo-Core) — PicGo 的命令行版本，Typora 可直接调用；不需要桌面界面时可以选它。
- [uPic](https://github.com/gee1k/uPic) — macOS 原生图片和文件上传工具，支持拖拽、剪贴板和快捷键上传。更新较少，适合想用原生应用的 Mac 用户。
- [Upgit](https://github.com/pluveto/upgit) — 上传文件并生成直链，可接入 Typora 的自定义图片上传功能。上传前确认目标仓库或存储服务是否公开。
- [typora-plugin-bilibili](https://github.com/xlzy520/typora-plugin-bilibili) — 将图片上传到哔哩哔哩并替换文档中的链接。当前可用性待确认。

PicGo、PicList、PicGo-Core 和 uPic 都有 [Typora 官方接入说明](https://support.typora.io/Upload-Image/)。选好工具后，再配置自己的图床。

## 导出与图表

- [Pandoc](https://github.com/jgm/pandoc) — 文档格式转换工具。Typora 的 Word、EPUB、LaTeX 等部分导入导出功能依赖它，按[官方安装说明](https://support.typora.io/Install-and-Use-Pandoc/)配置即可。
- [Mermaid](https://github.com/mermaid-js/mermaid) — 用文本画流程图、时序图、甘特图等。Typora 已内置支持，不必再装同名插件；具体语法以 Typora 内置版本为准，参考[图表用法](https://support.typora.io/Draw-Diagrams-With-Markdown/)。

## 学习资料

- [Typora 官方主题库](https://theme.typora.io/) — 按缩略图浏览更多主题，也可以提交自己制作的主题。
- [Typora 官方文档](https://support.typora.io/) — 查找编辑、主题、图片和导出等功能的用法。
- [《了不起的 Markdown》](https://book.douban.com/subject/37478156/) — 一本介绍 Markdown 语法、工具和写作应用的书，链接为图书介绍页。

发现链接失效或说明有误，也欢迎指出。这份清单没有逐项安装测试，具体插件的使用问题请到对应项目反馈。
